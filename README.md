This is an ai assisted project that ports the 1994-1995 "DoomEd - The Real Thing" application by Geoff Allan.
The initial stages were a simple port so it could run in modern Windows.
The next stage added several features that were in-progress at the time the original project was dropped.
The final stage will be adding completely new features that I was unable to code at the time.

As it stands, this is an extremely simple, yet highly functional, editor for creating and modifying Doom maps.

Features:
* Full 3D render of the map as it will appear in the game.
* Ability to edit maps in real time while seeing exactly how the map will appear. This is useful for adjusting textures so they line up properly
* Ability to select entire pieces of architecture as a Group, save that, and insert it into another map
* Standard copy/paste and Undo functionality

WHY?
Retro-gaming is still fun. Doom runs well on very low-resource computers, most of us played it on a 386 or 486 processor. Also, I always regretted never finishing this editor, but I had run into some personal issues that took me away from it.

To use this editor, you will need Doom. Luckily it is available at https://github.com/saliukkurulo/TheUltimateDoom
